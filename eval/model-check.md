# Проверка PDF Desk с реальной моделью

Дата основного прогона: **3 октября 2026 года**. Окружение: macOS, Python **3.12.13**, PageIndex **0.2.20**, Streamlit **1.64.0**, pypdfium2 **5.13.0**. Таблица ответов получена до первого коммита; браузерная проверка и CI проведены после публикации. Ни один API-ключ не записывался в репозиторий.

## Сценарий

Использован `data/demo-manual.pdf`, созданный командой `python tests/make_demo_pdf.py`: 3 страницы, SHA-256 `7b412a8c5f92137bd9b442aadbcdf8d3a00e4cdd9b95175bf87d412cec73362e`. Индекс и временные настройки создавались вне репозитория и удалялись после прогона. Тестовый PDF содержит сведения о гарантии, условиях её прекращения и часах поддержки, но не содержит цены.

Провайдер: **DeepSeek API**, адрес `https://api.deepseek.com/v1`, модель `deepseek-flash` для подготовки и ответов. Ключ был взят из локального хранилища учётных данных без вывода в консоль. Имена модели и адрес соответствуют [документации DeepSeek](https://api-docs.deepseek.com/guides/tool_calls/).

Проверка `reader.check_connection()` прошла: модель вернула обычный текстовый ответ и выполнила вызов функции `ping`. Затем `app.prepare_document()` подготовила 3 страницы без предупреждений. Каждый вопрос был передан отдельно через `app.answer_question()`.

| Вопрос | Фактический результат модели | Страницы, принятые приложением | Оценка по PDF |
|---|---|---|---|
| Какой срок гарантии? | «Срок гарантии — 18 месяцев» | 2 | Верно |
| Когда гарантия перестаёт действовать? | При вскрытии корпуса; модель также упомянула срок 18 месяцев | 3, 2 | Верно; страница 2 относится к дополнительному утверждению |
| Когда работает поддержка? | С понедельника по пятницу, 09:00–18:00 | 3 | Верно |
| Сколько стоит устройство? | Модель сообщила, что цена в документе не указана и ответить по нему нельзя | 1, 2, 3 | Верно; ссылки охватывают весь документ, потому что утверждается отсутствие цены |

Во всех четырёх ответах список предупреждений приложения был пуст. Первый ответ после дополнительной правки форматирования был повторно проверен с реальной моделью: **«Срок гарантии составляет 18 месяцев.»**, страница **2**, предупреждений нет. Эта правка убрала пробел перед точкой, остававшийся после удаления тега источника; остальные три вопроса после неё не повторялись.

### Повтор через браузер

После публикации репозитория тот же короткий PDF проверен через настоящий интерфейс Streamlit в headless Chrome. Браузерная автоматизация ввела настройки DeepSeek в боковую панель и нажала «Проверить подключение»; приложение показало «Подключение работает». Затем она загрузила `demo-manual.pdf`, нажала «Подготовить документ» и дождалась сообщения «Документ готов». На вопрос «Какой срок гарантии?» интерфейс вывел **18 месяцев** и кнопку **«Источник 1 · страница 2»**. Нажатие этой кнопки открыло **«Страница PDF 2 из 3»** рядом с ответом. Все пять шагов прошли. Ключ читался только в память тестового процесса из локального хранилища; временный индекс находился вне репозитория.

Первоначальная таблица выше получена через функции приложения с настоящим PageIndex SDK и внешним API. Браузерный прогон повторил один вопрос и проверил весь путь от полей настройки до перехода к странице. Правильность ответа оценена по содержимому короткого демонстрационного PDF; результат не доказывает качество на произвольных документах, сканах и таблицах.

## Подписка OpenCode Go

Ключ OpenCode Go отвечает в самом OpenCode: вызов модели `opencode-go/glm-5.3-flash` через CLI успешно дал ответ на вопрос о совместимости синтаксиса Python 3.7. Следовательно, неуспех подключения PDF Desk не доказывает неверность ключа.

`reader.check_connection()` с адресом `https://opencode.ai/zen/go/v1` и моделью `glm-5.3-flash` завершилась сообщением приложения «Сервер отклонил ключ». Прямой запрос к `/chat/completions` с явным User-Agent получил HTTP 400 `MissingSessionID`: отсутствует заголовок `x-opencode-session`. [Документация OpenCode Go](https://opencode.ai/docs/go/#where-can-i-use-it) требует стабильный идентификатор сессии и описывает сервис как предназначенный для coding agents. PDF Desk — приложение для вопросов к документам; полноценную индексацию PDF через Go не проводили. **OpenCode Go не считается проверенным провайдером PDF Desk.**

## Локальные проверки

- `python -m pip check` — конфликтов зависимостей нет.
- `python -m unittest discover -s tests -q` — **44 теста, OK** на macOS с Python 3.12.13. Streamlit AppTest выводит предупреждения о `ScriptRunContext` при работе без браузера; они не являются падением тестов.
- Тестовые временные пути приводятся к реальному пути, чтобы системная ссылка `/var` на macOS не вызывала ложный отказ защитной проверки символьных ссылок.
- Снимок реального интерфейса находится в [`assets/app-screenshot.png`](../assets/app-screenshot.png). На нём открыт русскоязычный PDF без подключённой модели; изображение не выдаётся за запись успешного модельного прогона.
- [CI на Python 3.11 и 3.12](https://github.com/balyakin/pdf-desk/actions/runs/37105930978) завершился успешно на опубликованном коммите `1bbb5f0`.

## Границы результата

Проверен один короткий PDF и один внешний провайдер для полной цепочки. Не проверены производительность и стоимость на больших документах, качество OCR (его в проекте нет), Windows, Linux в этой сессии, многопользовательская работа и пилот с людьми по [`eval/pilot.md`](pilot.md). Тесты с подставным клиентом не заменяют эту внешнюю проверку, а внешний прогон не заменяет тесты ошибок и границ входных данных.
