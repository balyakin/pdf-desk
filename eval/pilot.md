# Пилот PDF Desk

Результаты пока не собирались. Участники — 3–5 русскоязычных людей без опыта Python, которым нужно найти сведения в инструкции или учебнике PDF. Это рабочее предположение об аудитории.

Сравниваем PDF Desk с **готовым приложением PageIndex**, а не с вызовами его SDK. До начала зафиксируйте доступную версию или дату сервиса, URL и тариф. Если сравнимый интерфейс PageIndex недоступен, проведите пилот одного PDF Desk и прямо укажите отсутствие сравнения.

## Перед началом

- Дата и наблюдатель: __________
- PDF Desk: версия/снимок файлов __________
- Python / PageIndex SDK / Streamlit / PDFium: __________
- Готовое приложение PageIndex, URL и версия/дата: __________
- ОС, браузер, компьютер и сеть: __________
- Сервер модели, модель индекса и модель ответов, **без ключей**: __________
- PDF: `data/demo-manual.pdf`, SHA-256 __________
- Второй PDF с текстовым слоем для замены, одинаковый для всех: имя __________, SHA-256 __________
- Условия внешнего API и тариф, лимит расходов проверки: __________
- Различия между моделями/обработкой в двух приложениях: __________

Подготовьте два одинаковых PDF и единый текст заданий для обоих приложений. Не подсказывайте названия кнопок. Для PageIndex учитывайте регистрацию, получение ключа и настройку, если они нужны. Измеряйте установку, настройку, подготовку PDF и ожидание модели отдельно. Если второй PDF не подготовлен, задание замены считается неподготовленным; не выдумывайте его результат.

Сообщите участнику, какой сервер получит текст документа и какие запросы могут быть платными. Используйте несекретные материалы. Ключ вводит сам участник; в бланк, снимки экрана и журнал его не записывайте. Участник может завершить попытку в любой момент.

Распределите порядок до испытания: участники 1, 3, 5 начинают с PDF Desk, участники 2, 4 — с PageIndex. Второй заход обучает пользователя; сохраняйте результаты обоих заходов с указанием порядка. До второго приложения не разбирайте ошибки первого вместе с участником.

## Задания участнику

1. По предоставленной инструкции запустите приложение и настройте доступ к модели.
2. Добавьте руководство Alpha-7 и дождитесь готовности документа.
3. Узнайте срок гарантии. Откройте источник и проверьте, совпадает ли он с ответом.
4. Узнайте, когда гарантия перестаёт действовать и когда работает поддержка. Для каждого ответа проверьте страницу.
5. Узнайте цену устройства. Решите, достаточно ли оснований доверять ответу.
6. Замените руководство вторым предоставленным PDF. Убедитесь, что активен именно новый документ и старый ответ не представлен как ответ по нему.

Наблюдатель не подсказывает, пока участник явно не попросит помощи. Каждую подсказку запишите с временем и причиной. Если участник остановился, сохраните затраченное время, последний достигнутый шаг и причину. Не исключайте незавершённые попытки из числа участников.
